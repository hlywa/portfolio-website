My little corner of the internet. A personal website for my games, research, writing, and other experiments.

I want this site to feel like a strange, living place you can explore, rather than a traditional portfolio.

The homepage is a constellation of floating text charms. You can hover over them, move them around, and discover hidden links and little surprises. Some things are obvious. Others reward curiosity.

｡･:*˚:✧｡

## The idea

I'm interested in games as systems for thought, expression, and discovery. I want the website itself to reflect that.

A few things I'm exploring:

- Animated ASCII-inspired and Unicode glyphs
- Objects that respond to touch, movement, and proximity
- Hidden passages and playful interactions
- Generative behavior and unexpected discoveries
- A home for work that doesn't fit neatly into one category

## The site

**About** · **Work** · **Contact**

Work includes my creative projects, research, games, writing, and experiments. I don't want to separate these too strictly because they often overlap.

## Making it

Built with HTML, CSS, and JavaScript, with room to experiment with p5.js.

This is also a way for me to learn creative coding by building something of my own.

## Running it

Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Finding things

- `index.html` — content, links, and glyphs
- `style.css` — appearance and animation
- `script.js` — interactions and hidden discoveries
